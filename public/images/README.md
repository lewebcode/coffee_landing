# Изображения лендинга

Локальные файлы: `logo.png`, `hero-bg.png`, `process1.png` и др.

**Скачать недостающие ассеты:**

```bash
node scripts/download-assets.mjs
```

Если Figma возвращает ошибки (нет доступа без авторизации), откройте ссылки из скрипта в браузере, будучи залогиненными в Figma, и сохраните файлы сюда с именами: `hero-play-circle.png`, `hero-play-icon.png`, `search-icon.png`, `cart-icon.png`, `process2.png`, `process3.png`, `history1.png`, `history2.png`, `history3.png`, `cta-machine.png`.
